# وسيم ابودقة — متجر إلكتروني فاخر

متجر ويب كامل بHTML و CSS و JavaScript خالص، بواجهة عربية (RTL) وتصميم داكن فاخر بلمسات ذهبية.

## تشغيل المشروع

لا يحتاج المشروع أي تثبيت أو أدوات إضافية. افتح ملف `index.html` مباشرة في المتصفح، أو شغّل خادم محلي بسيط:

```powershell
python -m http.server 8000
```

ثم افتح الرابط: `http://localhost:8000`

## الملفات

| الملف | الوصف |
|------|-------|
| `index.html` | بنية الصفحات والأقسام والنوافذ المنبثقة |
| `styles.css` | التصميم، الثيم الداكن، RTL، والتجاوب مع كل الشاشات |
| `script.js` | المنتجات، الفلاتر، البحث، السلة، ونموذج الطلب |

## المزايا

- عرض المنتجات مع تصنيفات وفلاتر وبحث وخيارات ترتيب.
- سلة مشتريات كاملة (إضافة، تعديل كمية، حذف، تفريغ) محفوظة في المتصفح عبر `localStorage`.
- نافذة تفاصيل سريعة للمنتج ونافذة إتمام طلب مع رسالة نجاح.
- تصميم متجاوب للجوال والتابلت، مع حركات ظهور وأنيميشن خفيفة.
- صور احتياطية تلقائية إذا تعذّر تحميل الصور من الإنترنت.

> ملاحظة: الصور تُحمّل من روابط خارجية (Unsplash) والخطوط من Google Fonts، لذا تحتاج اتصالاً بالإنترنت لظهورها. في حال عدم توفر الإنترنت تظهر بدائل جذابة تلقائياً.

## تخصيص المتجر

- لتعديل المنتجات: افتح `script.js` وعدّل مصفوفة `products` في الأعلى.
- لتعديل الألوان: افتح `styles.css` وعدّل المتغيرات داخل `:root` في الأعلى.
